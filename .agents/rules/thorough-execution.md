# Thorough Execution Rule

Whenever executing a multi-step plan or complex task:

1.  **Checklists:** Always create and maintain complete checklists. Define clear Acceptance Criteria and a Definition of Done (DoD) for each task in the plan.
2.  **Quality Control:** Fix all errors, messes, and bugs. Ensure there are no type errors, reference errors, or hidden issues.
3.  **No Tech Debt:** Actively debloat code and leave absolutely zero technical debt behind.
4.  **Relentless Completion:** Proceed until everything is 100% complete. Do not stop early. Keep working until the result is golden.
5.  **Sequential Execution:** Proceed to the next task only if the current task is completely "green" (passing all checks).
