# Communication Preferences

The user has defined specific communication preferences based on tags they might use in their prompts:

- **When the user includes `[KH]`:** You MUST respond entirely in the Khmer language.
- **When the user includes `[EN]`:** You MUST respond in beginner-friendly, simple English.
  - If you absolutely must use a complex or technical word, you must explain it immediately using the format `[explanation: ... ]`.
